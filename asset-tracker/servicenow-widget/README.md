# ServiceNow widget export

This folder documents the `asset-tracker` Service Portal widget deployed to the
`x_189579_asset_t_0` application scope.

- **Widget ID:** `asset-tracker`
- **ServiceNow table:** `sp_widget`
- **Sys ID:** `427c5620c31b43102d8871edd4013173`

The widget is assembled from the browser app files in the parent directory:

- `../index.html` provides the widget template content inside `<body>`
- `../styles.css` provides the widget CSS
- `../app.js` provides the widget client script

This keeps the GitHub backup auditable while preserving the original source
files as the canonical version.
